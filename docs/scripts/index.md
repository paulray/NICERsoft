# Script reference

The command-line scripts in `scripts/` are installed on your `PATH` by
`pip install`. Each script prints the same information as these pages with
`--help`.

Many scripts need HEASoft initialized, and the spectral scripts need PyXspec
(see {doc}`../installation`).
